# Portafolio Personal | Daniel Ledezma Castro

Sitio web y portafolio interactivo desarrollado con **React 19**, **Vite** y **Tailwind CSS**, diseñado para presentar proyectos de desarrollo Full Stack, soluciones móviles e integraciones de automatización e IoT.

🌐 **Demo en vivo:** [portafolio-dael2.vercel.app](https://portafolio-dael2.vercel.app)

---

## ⚡ Tecnologías Utilizadas

- **Framework:** [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Estilos:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Animaciones:** [Framer Motion](https://www.framer.com/motion/) & Canvas Particles
- **Iconos:** [Lucide React](https://lucide.dev/)
- **Despliegue:** [Vercel](https://vercel.com/)

---

## 🚀 Características Principales

- **Diseño Responsivo:** Adaptado para dispositivos móviles, tablets y pantallas de escritorio.
- **Micro-interacciones:** Animaciones suaves, cursor interactivo y transiciones de sección.
- **Secciones:**
  - **Hero:** Presentación y llamada a la acción.
  - **Sobre Mí:** Perfil profesional, estadísticas y enfoque técnico.
  - **Habilidades:** Visualización categorizada de stack tecnológico.
  - **Proyectos:** Galería interactiva de proyectos con filtrado por categoría.
  - **Servicios & Certificaciones:** Respaldo técnico y áreas de especialidad.
  - **Contacto:** Enlaces directos a WhatsApp, LinkedIn y correo electrónico.

---

## 🛠️ Instalación y Uso Local

```bash
# 1. Clonar el repositorio
git clone https://github.com/dalitoled/portafolio.git
cd portafolio

# 2. Instalar dependencias
npm install

# 3. Iniciar servidor de desarrollo
npm run dev

# 4. Compilar para producción
npm run build
```
